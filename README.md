# HA Wall Eurasburg – Add-ons

Eigene Home-Assistant-Add-ons rund um das Wandpanel
[HA Wall Eurasburg](https://github.com/Max6025/Hawall-Eurasburg).

## Installieren

Home Assistant → **Einstellungen → Add-ons → Add-on-Store** → oben rechts das Dreipunkt-Menü →
**Repositories** → diese Adresse hinzufügen:

```
https://github.com/Max6025/Hawall-Addons
```

Danach erscheinen die Add-ons unten im Store.

## Enthalten

| Add-on | Aufgabe |
|---|---|
| **[Wartungsmelder](wartungsmelder/DOCS.md)** | Legt Wartungen in Uptime Kuma an, wenn an einem Gerät gearbeitet wird, und entfernt sie danach wieder. Ausgelöst über HTTP. |
